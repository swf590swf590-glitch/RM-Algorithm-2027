## 二、第一次作业：数组反转

### 2.1 学习到的知识

- 在函数参数 `int* arr` 中，`arr` 指向传入数组的首元素。
- `p + 2` 对于 `int*` 指针表示后移两个 `int` 元素，而不是按字节加2。
- 使用两个指针分别从数组两端向中间移动，可原地交换元素，不需要新建数组。
- 函数的 `n` 是调用者传入的待处理长度，指针形参本身不能自动告诉函数原数组总长度。

### 2.2 遇到的问题与修正

1. 最初尝试 `int* left = arr[0]`：混淆了整数值和地址，改为 `int* left = arr`。
2. 最初尝试 `arr[-1]` 访问末元素：混淆了 Python 与 C++ 的下标规则，改为根据 `n` 获取末元素地址。
3. 最初尝试在交换语句中多次使用 `left++` 和 `right--`：导致指针移动次数不正确；修正为先交换，后分别移动指针。
4. 最初尝试打印 `void` 函数的返回值：学习到反转函数直接修改原数组，应该调用后再输出数组。

## 三、第二次作业：爬楼梯（递归与迭代）

### 3.1 学习到的知识

- 根据“最后一次走 1 阶或 2 阶”建立递推式 `f(n) = f(n-1) + f(n-2)`，约定 `f(0) = f(1) = 1`。
- 递归通过函数调用自身分解问题，必须设置能到达的终止条件；迭代从初始值开始，利用循环更新前两个结果。
- 在迭代循环中，先计算 `next = a + b`，再依次执行 `a = b`、`b = next`，避免覆盖上一轮需要的变量。
- 使用 `std::cin` 读入整数，`std::cout` 输出 `long long` 结果，用 `std::boolalpha` 输出布尔值。

### 3.2 遇到的问题与修正

1. 最初混用递归与迭代，在递归函数中尝试使用循环和两个状态变量；后改为 `f(n-1) + f(n-2)` 的递归调用。
2. 忘记声明迭代中的 `next` 变量，补充 `long long next`。
3. 输出比较表达式时未加括号，导致运算符优先级问题；修正为 `(result1 == result2)`。
4. PowerShell 最初位于 `C:\\WINDOWS\\System32`，编译器无法找到源代码；改从保存 `stairs.cpp` 的文件夹打开 PowerShell 后解决。
